# Design System: Typography

DormDesk uses a clean, system-native typography scale to ensure fast load times and a professional appearance without custom font loading overhead.

## Font Family
- **Sans-serif:** `Inter`, `system-ui`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, `Roboto`, `Helvetica Neue`, `sans-serif`.
- **Monospace:** `ui-monospace`, `SFMono-Regular`, `Menlo`, `Monaco`, `Consolas`, `monospace` (For request IDs and audit logs).

## Heading Scale
- **H1 (Page Title):** 24px (1.5rem), `font-semibold`, Tracking tight.
- **H2 (Section Title):** 20px (1.25rem), `font-semibold`, Tracking tight.
- **H3 (Card Title / Modal Title):** 16px (1rem), `font-semibold`.
- **H4 (Group Label):** 14px (0.875rem), `font-medium`, Uppercase, Letter-spacing wider.

## Body Scale
- **Body Large:** 16px (1rem), `font-normal`, Line height 1.5.
- **Body Default:** 14px (0.875rem), `font-normal`, Line height 1.5. (Primary text size for tables and cards).
- **Body Small (Caption/Metadata):** 12px (0.75rem), `font-normal`, Line height 1.4.

## Monospace & Technical
- **Request ID / Code:** 13px, `font-mono`, `font-medium`. Example: `#REQ-2026-042`.

## Font Weights
- **Normal:** 400
- **Medium:** 500 (Used for buttons, tabs, interactive labels)
- **Semibold:** 600 (Used for headings)
